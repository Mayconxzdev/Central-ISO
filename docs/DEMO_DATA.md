# Dados da demonstração

Todo conteúdo em `demo_iso/` é sintético e existe apenas para validar o piloto publicamente.

- nomes de pessoas são fictícios;
- fornecedores usam rótulos `FABRICANTE DEMO`;
- identificadores de certificados usam a marca `DEMO`;
- cenários de não conformidade são exemplos genéricos;
- nenhum arquivo aponta para infraestrutura corporativa real.

A demo foi deliberadamente separada do contexto privado para que testes, documentação e interface possam ser executados sem compartilhar dados de terceiros.
